Google 試算表同步教學

約 5 分鐘即可完成。資料會存在您自己的 Google 試算表，可跨裝置同步。

步驟 1：建立試算表與標題列

  1. 前往 sheets.new 建立新的空白試算表，可命名為「每日工作紀錄」。
  2. 在第 1 列依序填入標題（A～D 欄）：日期、內容、標籤、更新時間。
  3. 資料會寫入「目前使用中的工作表」，請保持只有一個工作表，或確保要寫入的工作表是開啟時的第一個分頁。

步驟 2：貼上 Apps Script 程式碼

  1. 在試算表選單點「擴充功能 → Apps Script」。
  2. 刪除編輯器內原有的 function myFunction() {}。
  3. 按下方按鈕複製程式碼並貼上。把第一行 const TOKEN = '' 的引號內改成自己的密碼（例如 'my-secret-123'），之後在 App「設定 → 同步密碼」填入同一組，按 Ctrl/⌘ + S 儲存。

常見問題

    
    
      
  • 修改程式碼後沒生效：每次改程式碼都要「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」，網址不變。
    • 
      
  • 同步失敗：確認「誰可以存取」為「所有人」、網址結尾是 /exec（不是 /dev）。
    • 
      
  • 同步規則：每筆記錄都有「更新時間」，以較新的一方為準；刪除也會同步。若兩台裝置離線時都改了同一天，較新的版本會成為主文，較舊版本另存於「更多 → 同步衝突版本」（只存本機，不會寫入主文或試算表），可還原或刪除。在試算表手動修改內容時會自動更新時間。更新應用程式後，請重新複製程式碼貼進 Apps Script 並重新部署（管理部署作業 → 編輯 → 新版本）。
    • 
      
  • 同一天只保留一列：以日期為鍵，重複同步會更新而非新增。
    • 
      
  • 隱私：請務必設定同步密碼，否則知道網址的人都能讀寫您的試算表。網頁本身不含任何個人資料，資料只存在各裝置瀏覽器與您的試算表。

# 每日工作紀錄

> 零依賴、單一 HTML 檔的每日工作日誌 PWA：本機自動儲存，可選用 AI 整理／回顧報告與 Google 試算表跨裝置同步。

## ✨ 功能亮點

- **每天一篇、自動儲存**：直接書寫，內容即時存入瀏覽器 `localStorage`，支援 Markdown 預覽與標籤。
- **回顧、搜尋與統計**：月曆瀏覽、全文搜尋、標籤與日期區間篩選、排序；可展開本週／本月統計（記錄天數、連續天數、字數、標籤分布）。
- **備份匯出／匯入與回收桶**：備份檔不含 API Key、同步密碼與同步網址；匯入可選「合併（較新者為準）」或「覆蓋」。單日刪除的內容保留在回收桶，可隨時還原。
- **AI 整理與回顧報告（BYOK）**：自備 API Key，使用任何 OpenAI 相容 API（OpenAI、Groq、DeepSeek 等）整理當天記錄，或把本週／本月多日記錄彙整成回顧報告；結果可複製或附加到今天。
- **待辦清單可勾選**：Markdown 預覽中的 `- [ ]` 方塊可直接勾選，勾選結果會回寫原文並自動儲存／同步。
- **Google 試算表雙向同步**：資料存在你自己的試算表，手機與電腦共用；以「更新時間較新者為準」，雙邊同時修改時以較新者為主文，較舊版本另存於「同步衝突版本」，不會寫入主文或遺失。
- **PWA／離線可用**：可安裝到手機主畫面，Service Worker 讓離線也能開啟。
- **外觀主題三態**：「跟隨系統／淺色／深色」可在設定切換，偏好只存本機、不寫入備份。
- **敏感欄位可見性切換**：API Key 與同步密碼輸入框右側的眼睛圖示可切換顯示內容，關閉設定視窗後自動回復隱藏。
- **單日匯出與容量預警**：可把當天記錄存成 `.md` 檔；本機儲存接近 5MB 上限時會顯示警示，提醒先匯出備份。

## 📋 系統需求

- 現代瀏覽器（Chrome、Edge、Safari、Firefox 近期版本）
- 不需要 Node.js、套件安裝或建置步驟
- 若要使用 PWA／離線功能：需以 `https://` 或 `http://localhost` 提供服務（`file://` 可使用基本功能，但 Service Worker 不會啟用）
- 選用：Google 帳號（同步）、OpenAI 相容的 API Key（AI 整理）

## 🚀 快速開始

### 安裝

```bash
git clone <此專案的 repo 網址>
cd daily_work_log
```

此專案沒有相依套件，不需要 `npm install`。

### 設定

不需要 `.env`。所有設定（API Key、同步網址等）都在 App 內的「更多 → 設定」填寫，並只存於本機瀏覽器。

API Key 與同步密碼欄位右側有眼睛圖示：按一下改為明文以便核對，再按一下回復遮蔽；圖示會在睜眼／斜線眼之間切換。此顯示狀態只存在於當前畫面，不會被儲存，**關閉設定視窗再開啟一律回到隱藏**，也不影響設定值與備份排除規則。

### 執行

最簡單：直接用瀏覽器開啟 `index.html`。

若要測試 PWA／Service Worker，請啟動本機伺服器：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

部署時，把整個資料夾放到任何靜態網站主機（GitHub Pages、Netlify、Cloudflare Pages 等）即可。

## 📖 使用說明

### 記錄

1. 開啟後預設為今天，直接在編輯區輸入內容，約停止輸入後自動儲存（狀態列顯示「已自動儲存」）。
2. 在「＋ 新增標籤」輸入標籤後按 Enter，可為當天加上標籤；已有的標籤可直接點選。
3. 按「預覽」切換 Markdown 預覽（預覽區雙擊可回到編輯）；`- [ ]` 待辦方塊可直接勾選，勾選結果會回寫原文並自動儲存。
4. 按編輯區右上角的垃圾桶圖示可刪除當天記錄；內容會移到「更多 → 回收桶」，可還原或永久刪除。若已啟用同步，刪除也會同步到試算表。
5. 「更多 → 匯出當天 Markdown」會把目前編輯日期的內容存成 `.md` 檔（標題為日期、含標籤），適合貼到其他筆記軟體；不影響同步與 JSON 備份。

### 回顧

- 手機點底部「回顧」，桌面版在左側欄。
- 月曆點選日期、搜尋框搜尋內容、「進階篩選」依日期區間與排序、點標籤篩選。
- 點「回顧統計與 AI 報告」展開面板，切換「本週／本月」查看記錄天數、連續記錄天數、總字數、平均字數與標籤分布前 5 名。
- 按「AI 報告」會把該範圍內的每日記錄交給同一組 BYOK 設定產生回顧報告（需先設定 API Key）。

### 快捷鍵

| 快捷鍵 | 功能 |
|--------|------|
| `Ctrl/⌘ + K` | 搜尋 |
| `Alt + ←` / `Alt + →` | 前一天／後一天 |
| `Alt + T` | 回到今天 |
| `Alt + P` | 切換 Markdown 預覽 |
| `Esc` | 關閉視窗 |

### AI 整理與回顧報告

1. 「更多 → 設定」填入 API Key（必要）、API Base URL 與模型名稱。
2. 在要整理的那天按上方「AI 整理」，在結果視窗選擇「附加到結尾」或「取代原文」。
3. 可在設定中自訂 System Prompt，「還原預設」可恢復內建提示詞（繁體中文條列摘要）。此提示詞只作用於單日整理。
4. 「回顧 → 統計面板 → AI 報告」使用內建的回顧提示詞，把範圍內所有日期的記錄彙整成週報／月報；結果可「複製」或「附加到今天」。兩者共用同一條 OpenAI 相容 API 管線與同一把 API Key。

### 備份與還原

「更多 → 匯出備份」會下載 JSON 檔。**備份檔不含 API Key、同步密碼與 Apps Script 網址**，內容包含每日記錄、標籤、更新時間、回收桶與衝突版本，可安心存放（但仍含有您的工作紀錄內容，請勿公開）。

「更多 → 匯入備份」選擇該 JSON 後會先顯示摘要（筆數、與本機重疊筆數），可選：

- **合併（較新者為準）**：保留本機較新的內容，只補進備份中較新或缺少的日期。
- **覆蓋本機記錄**：以備份取代全部本機記錄、回收桶與衝突版本（需二次確認）。

兩種模式都**不會變更本機設定**，也**不會帶入備份中的刪除狀態**，避免誤刪試算表資料。舊版本產生的備份若含有金鑰，匯入時會直接忽略。

「設定 → 清除所有本地記錄（含回收桶與衝突版本）」會連同刪除狀態一併清空。若已啟用試算表同步，雲端記錄會在下次同步時回到本機；要連雲端一起清除，請到試算表手動刪除。

### 外觀與儲存容量

「更多 → 設定 → 外觀」可選擇「跟隨系統／淺色／深色」，切換後立即套用。此偏好只存於本機 `localStorage`，**不會寫入備份檔**，匯入備份也不會變更它；「跟隨系統」會隨裝置設定即時切換。

瀏覽器 `localStorage` 常見上限約 5MB。本 App 每次成功儲存後會估算使用量，達 80%（約 4MB）即在頁面頂端顯示持續性警示；使用量降回門檻以下時會自動消失。看到警示請先「匯出備份」，再清理舊記錄、回收桶或衝突版本。若儲存寫入失敗（例如配額已滿），頂端會改為紅色警示，此時資料僅暫存在記憶體，關閉頁面即消失。

App 內「設定 → Google 試算表設定教學」（書本圖示按鈕）有完整圖文步驟與可一鍵複製的 Apps Script 程式碼，摘要如下：

1. 建立新試算表，**第 1 列** A～D 欄依序填：`日期`、`內容`、`標籤`、`更新時間`。
2. 「擴充功能 → Apps Script」貼上教學提供的程式碼，並把第一行 `const TOKEN = ''` 改成你自己的密碼。
3. 「部署 → 新增部署作業 → 網頁應用程式」：執行身分選「我」、存取權選「所有人」，授權後複製 `.../exec` 網址。
4. 回到 App「設定」貼上網址與同樣的密碼，按「儲存」。

同步行為：

- 開啟或切回頁面時自動拉取；編輯停止約 2 秒後自動上傳；也可手動按「同步」。
- 同一天只保留一列（以日期為鍵）；刪除也會同步。
- 兩台裝置離線時都改了同一天：較新版本成為主文，較舊版本另存於「更多 → 同步衝突版本」（只存本機、不參與同步上傳），可還原成主文或刪除；還原時原主文也會被保留為另一個衝突版本。
- 手機：用手機瀏覽器開啟同一網頁並填入相同網址與密碼；iPhone 用 Safari「分享 → 加入主畫面」，Android 用 Chrome「安裝應用程式」。

## ❓ 常見問題（FAQ）

**資料存在哪裡？**
預設只存在目前瀏覽器的 `localStorage`（含回收桶與衝突版本）。清除瀏覽器資料或換瀏覽器會看不到；請定期匯出備份或啟用試算表同步。回收桶與衝突版本只存本機，不會同步。

**同步失敗怎麼辦？**
確認網址結尾是 `/exec`（不是 `/dev`）、部署的「誰可以存取」為「所有人」、同步密碼與 Apps Script 的 `TOKEN` 一致。

**更新 App 後同步異常？**
重新複製教學中的程式碼貼進 Apps Script，並到「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」（網址不變）。

**AI 整理失敗？**
檢查 API Key、Base URL 與模型名稱；請求由瀏覽器直接送出，服務端需允許跨來源（CORS）。

**備份檔包含 API Key 或同步密碼嗎？**
不包含。匯出時會排除 API Key、同步密碼與 Apps Script 網址；匯入時也完全不讀取備份內的設定。舊版備份若含這些欄位，匯入時會被忽略。

**統計的「連續記錄天數」怎麼算？**
從今天往前算連續有內容的天數；若今天還沒寫，則從昨天起算，範圍不限於本週／本月。字數不計空白，標籤分布以「出現天數」計算並取前 5 名。

**頁面頂端出現「本機儲存已使用約…」警示怎麼辦？**
瀏覽器 `localStorage` 常見上限約 5MB，達 80% 時會預警。請先「更多 → 匯出備份」，再清除舊記錄、回收桶或衝突版本；若已啟用試算表同步，雲端仍保有資料。此警示在使用量降回門檻以下時會自動消失。

**主題設定會跟著備份帶到別台裝置嗎？**
不會。主題屬介面偏好，只存本機且不寫入備份檔；匯入備份也不會變更本機主題。

**更新 App 後畫面沒變？**
Service Worker 為網路優先，重新整理即可取得新版；若仍是舊版，可在瀏覽器開發者工具清除該網站的快取。

## 🔒 隱私與安全注意

- API Key 與同步密碼以明碼存於本機 `localStorage`，請勿在不信任的共用電腦上使用。
- 眼睛圖示可短暫顯示 API Key 與同步密碼，核對時請留意身旁螢幕與螢幕錄製；關閉設定視窗即自動回復隱藏。
- 匯出備份已排除 API Key、同步密碼與同步網址；備份檔仍含有工作紀錄內容，請勿公開或傳給他人。
- 請務必設定同步密碼，否則任何知道 Apps Script 網址的人都能讀寫你的試算表。
- 單日 AI 整理只送當天內容；AI 回顧報告會把所選範圍內的每日記錄一併送往你設定的 AI 服務。
- 內容只會送往你設定的 AI 服務與你自己的 Apps Script，本專案沒有任何自有後端。
- 本機儲存接近上限時會顯示容量警示；請定期匯出備份，避免寫入失敗導致資料只留在記憶體。
